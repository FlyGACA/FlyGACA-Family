# Individuals funnel content package

**Status:** draft. Prices, discounts, the welcome emails and Captain Adel usage limits wait for owner approval.
**Owner:** Brand. **Consumers:** Platform (FlyGACA web, iOS), Commerce (FlightBag, Gallery), Captain Adel.

This folder is the source of truth for the Individuals funnel copy: the path from a short video to a free sample, an email signup and a paid tier. Product code stays in the owning repositories; this package holds only copy and the commercial proposal.

Arabic counterparts carry the `_AR` suffix and mirror these sections one to one.

## Funnel in one line

TikTok, Reels and YouTube → free chapter and twenty questions → email signup → tier offer → upgrade or subscription.

## Rules for this package

- Branch and PR only. No merge, deploy or send without the owner.
- Do not publish prices, discounts or outbound email until the owner approves them.
- Arabic needs native review before anything is published.
- Payments run in Moyasar test mode only; no live keys and no live charges.
- Every public surface carries the non-affiliation notice in both languages.
