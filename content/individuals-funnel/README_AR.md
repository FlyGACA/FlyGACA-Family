# حزمة محتوى مسار الأفراد

**الحالة:** مسودة. الأسعار والخصومات ورسائل الترحيب وحدود استخدام الكابتن عادل تنتظر موافقة المالك.
**المالك:** البراند. **المستهلكون:** Platform (موقع FlyGACA وتطبيق iOS)، Commerce (FlightBag والمعرض)، الكابتن عادل.

هذا المجلد هو المصدر المعتمد لنصوص مسار الأفراد: الطريق من مقطع قصير إلى عيّنة مجانية، ثم تسجيل بالبريد الإلكتروني، ثم اشتراك مدفوع. يبقى كود المنتج في المستودعات المالكة له، ولا تحتوي هذه الحزمة إلا النصوص والعرض التجاري.

## المسار في سطر واحد

تيك توك وريلز ويوتيوب ← فصل مجاني وعشرون سؤالًا ← تسجيل بالبريد الإلكتروني ← عرض الفئة ← ترقية أو اشتراك.

## قواعد هذه الحزمة

- فرع وطلب سحب فقط. لا دمج ولا نشر ولا إرسال دون موافقة المالك.
- لا تُنشر الأسعار أو الخصومات أو الرسائل البريدية قبل اعتماد المالك لها.
- النص العربي يحتاج مراجعة من متحدث أصلي قبل النشر.
- المدفوعات في وضع اختبار Moyasar فقط؛ لا مفاتيح حقيقية ولا عمليات فعلية.
- كل واجهة عامة تحمل إشعار عدم التبعية باللغتين.
